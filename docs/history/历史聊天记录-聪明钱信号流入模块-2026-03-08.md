# 历史聊天记录：聪明钱信号流入模块（2026-03-08）

本记录保存「榜单页新增 binance 聪明钱信号 Tab + 信号卡片」的需求、实现与文件改动。

## 1. 需求背景

**用户需求**：在榜单页增加「聪明钱信号流入」功能模块，参考截图所示 UI：
- 在「zhilabs 精选」旁边增加 Tab，命名为「binance聪明钱信号」
- 该 Tab 下展示信号卡片网格，每张卡片包含：代币头像/名称/合约、流动性/市值/平均买入价、时间文案（如「Xm以前买入」）、「X个聪明钱正在交易」、资金净流入（绿/红）、买入/卖出比例条

**设计约束**：前端风格需与项目现有榜单页、代币详情页一致（Design Tokens、Exo 2/Orbitron 字体、深色卡片与边框）。

## 2. 实现方案

### 2.1 数据与接口

- **数据源**：Binance Web3 Smart Money API（公开，无需 Key）
  - `POST https://web3.binance.com/bapi/defi/v1/public/wallet-direct/buw/wallet/web/signal/smart-money`
  - Body：`{ "smartSignalType": "", "page": 1, "pageSize": 100, "chainId": "CT_501" }`（Solana）
  - 返回字段：ticker、contractAddress、logoUrl、smartMoneyCount、direction、signalTriggerTime、totalTokenValue、alertPrice、alertMarketCap、currentMarketCap、exitRate、maxGain 等

### 2.2 架构概览

```
榜单页 /ranking
├── Tab: Solana Pump 榜单 | zhilabs 精选 | binance聪明钱信号
├── panel-pump / panel-zhilabs / panel-signal
└── signal 时：GET /api/smart-money-signals → renderSignalCards()
```

## 3. 功能要点

- **懒加载**：首次切换到「binance聪明钱信号」时才请求 `/api/smart-money-signals`
- **刷新**：该 Tab 下「更新」按钮文案为「刷新信号」，点击仅重新拉取信号数据，不调用 `/api/update`
- **交互**：卡片点击跳转 `/token/:contractAddress`；合约复制沿用现有 `.copy-ca-btn` 逻辑
- **样式**：复用 --bg-card、--border-subtle、--positive/--negative 等变量，与 [knowledge/smart-money-signal-ui.md](../../knowledge/smart-money-signal-ui.md) 一致

## 4. 后续可选

- 定时刷新：当前未纳入 scheduler，可按需为 signal 单独加轮询或调度分支
- 多链：API 支持 chainId（如 56=BSC），前端可增加链筛选

## 5. 2026-03-08 修复：图片加载与卡片数量说明

**问题 1：代币 Logo 图片损坏**
- **原因**：Binance CDN（bin.bnbstatic.com）可能因 Referer 策略拒绝来自外部站点的图片请求
- **修复**：
  - 为 `<img>` 添加 `referrerpolicy="no-referrer"` 减少被拒概率
  - 用 DexScreener 为每个信号补充 `logoUrlFallback`，主图加载失败时自动切换
  - 双重失败时显示首字母占位符（`.signal-card-logo-placeholder`）

**问题 2：一直是三张代币卡片**
- **说明**：非 bug。Binance 聪明钱信号 API 对 Solana（chainId=CT_501）当前仅返回 3 条活跃信号，数据由 Binance 侧决定，会随时间变化

## 6. 2026-03-08 更新：BSC 聪明钱流入 + 链标识

**用户需求**：在聪明钱信号板块增加 BSC 流入，并在代币卡片中针对 sol/bsc 字段区分展示。

**实现**：
- **API**：并行拉取 Solana（CT_501）+ BSC（56）信号，合并返回，每条附加 `chain`（'solana'|'bsc'）、`sol`、`bsc` 布尔字段
- **DexScreener 补充**：按链为 Sol/BSC 代币分别补充 `logoUrlFallback`，key 为 `chain:address`
- **卡片**：
  - 合约区域显示链标签（Sol / BSC），`.signal-card-chain` 样式，BSC 使用金色
  - `data-token`、`data-chain` 便于点击时传参
- **跳转**：点击卡片跳转 `/token/:address`（Solana）或 `/token/:address?chain=bsc`（BSC）
- **代币详情页**：从 URL `?chain=bsc` 读取链，请求 `/api/token/:address?chain=bsc`；链徽章与外部链接（DexScreener、Gecko、Solscan/BscScan）随 chain 切换

**文件改动**：`src/server.js`（API 合并、logo 按链补充、卡片链标签、点击传 chain、详情页 chain 支持）
