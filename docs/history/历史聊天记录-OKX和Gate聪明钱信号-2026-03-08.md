# 历史聊天记录：OKX 和 Gate 聪明钱信号（2026-03-08）

本记录保存「新增 OKX 聪明钱信号、Gate 聪明钱信号 Tab，使用 Binance 数据 + 各自品牌风格」的需求、实现与文件改动。

## 1. 需求背景

**用户需求**：增加 OKX 聪明钱信号和 Gate 聪明钱信号，数据先使用 Binance 的，但卡片风格需分别采用：
- **OKX**：黑色风格
- **Gate**：蓝色风格

**现有基础**：榜单页已有「binance聪明钱信号」Tab，数据来自 Binance Web3 API，卡片为金黄（`--bn-yellow`）风格。

## 2. 实现方案

### 2.1 数据与接口

- **数据源**：沿用 Binance Web3 Smart Money API，三个 Tab（binance / okx / gate）共用同一接口 `/api/smart-money-signals`
- **无新增 API**：okx、gate 仅改变前端卡片样式（variant），数据与 binance 完全相同

### 2.2 架构概览

```
榜单页 /ranking
├── Tab: Solana Pump 榜单 | zhizhilabs 精选 | binance聪明钱信号 | okx聪明钱信号 | gate聪明钱信号
├── panel-pump / panel-zhilabs / panel-signal / panel-okx-signal / panel-gate-signal
└── 信号 Tab 时：GET /api/smart-money-signals → renderSignalCards(list, rootId, variant)
    variant: 'binance' | 'okx' | 'gate'
```

### 2.3 样式变体

| 变体 | 主色 | 背景 | 说明 |
|------|------|------|------|
| binance | `--bn-yellow` 金黄 | `#0d0c08` | 原有风格 |
| okx | `#e0e0e0` 灰白 | `#050505` | OKX 品牌黑底白字 |
| gate | `#00b4ff` 蓝 | `#050814` | Gate.io 品牌蓝 |

### 2.4 文件改动清单

| 文件 | 改动 |
|------|------|
| `src/server.js` | ① 新增 okx-signal、gate-signal Tab 与 panel ② renderSignalCards 增加 variant 参数，grid 加 `.signal-cards-okx` / `.signal-cards-gate` ③ refreshTab、switchTab、updateBtn 支持新 Tab ④ OKX 黑色、Gate 蓝色 CSS 变体 |
| `knowledge/smart-money-signal-ui.md` | 补充三种风格变体说明（binance/okx/gate） |

## 3. 功能要点

- **懒加载**：首次切换到 okx-signal 或 gate-signal 时才请求 `/api/smart-money-signals`
- **刷新**：三个信号 Tab 下「更新」按钮均为「刷新信号」，点击重新拉取并渲染到对应 panel
- **样式**：
  - OKX：`#050505` 背景，`rgba(255,255,255,0.08)` 边框，灰白强调色，买入/流入用 `#7dd3a8`
  - Gate：`#050814` 背景，`#00b4ff` 主色，LIVE 栏、买入条、Active 等蓝色高亮，与 Gate.io 品牌一致
