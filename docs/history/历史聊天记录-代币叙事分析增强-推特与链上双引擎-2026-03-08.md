# 历史聊天记录：代币叙事分析增强 — 推特与链上双引擎（2026-03-08）

本记录保存「从推特叙事专家方法论提取分析手段，结合链上数据构建双引擎叙事分析」的需求、方案设计、实现与测试全过程。

## 1. 需求背景

**原始问题**：代币叙事分析不准确。原有方案仅通过 OpenNews 按 symbol/name 搜索新闻，对小众 meme 代币覆盖率低，且缺少推特社交数据维度。

**用户提供**：`推特.md` 文件（Solana Meme 币 Twitter 叙事分析专家方法论），包含：
- CA 优先搜索策略（避免同名代币干扰）
- KOL 分层审计体系
- 传销号识别特征
- 叙事等级标准（S/A/B/C）
- 结构化评估输出模板

**追加需求**：用户询问是否有不依赖推特 API 的方法 → 新增链上叙事分析模块。

## 2. 方案设计

### 2.1 双引擎架构

```
┌──────────────────────────────────────────────┐
│                 叙事分析 API                   │
│         /api/token/:address/narrative         │
└────────┬────────────────────┬────────────────┘
         │                    │
   ┌─────▼─────┐      ┌─────▼──────────┐
   │ 推特引擎   │      │ 链上引擎（免费）│
   │ (需Token)  │      │ (无需任何Key)  │
   └─────┬─────┘      └─────┬──────────┘
         │                    │
   ┌─────▼─────┐      ┌─────▼──────────┐
   │ OpenTwitter│      │ DexScreener    │
   │ 6551 API   │      │ GoPlus Security│
   └───────────┘      └────────────────┘
         │                    │
         └────────┬───────────┘
            ┌─────▼─────┐
            │ 智能合并   │
            │ 40%/60%   │
            └───────────┘
```

### 2.2 推特叙事引擎（来自方法论文件）

| 组件 | 方法 | 来源 |
|------|------|------|
| CA 优先搜索 | 合约地址全文 → cashtag → 名称 | 推特叙事专家 |
| KOL 分层 | Tier1(≥500K) / Tier2(≥50K) / Tier3(≥10K) / Tier4 | 推特叙事专家 |
| 传销号检测 | 新号(<6月)+无实质、付费标记、纯CA+emoji | 推特叙事专家 + 原有 |
| 叙事评级 | S/A/B/C（基于 KOL 分布 + 传销号占比） | 推特叙事专家 |
| 有机度评分 | 0-100 综合评分 | 自研 |

### 2.3 链上叙事引擎（完全免费）

| 维度 | 数据源 | 指标 | 满分 |
|------|--------|------|------|
| 市场健康度 | DexScreener | 交易量/市值比、流动性深度、交易频次、买卖比 | 30 |
| 社区健康度 | GoPlus + DexScreener | 持币人数、Top10 集中度、交易对数、市值 | 25 |
| 安全评估 | GoPlus | LP 锁定、铸币权、冻结权、蜜罐、风险等级 | 25 |
| 项目成熟度 | DexScreener | 代币年龄、Profile、Twitter/TG/Web 链接 | 20 |

等级判定：≥70 → S / ≥55 → A / ≥35 → B / <35 → C

### 2.4 智能合并策略

- 推特 + 链上都有 → 加权合并（推特 40% + 链上 60%，链上更客观）
- 仅链上 → 纯链上分析（不依赖推特 API 也能完整评估）
- 仅推特 → 推特分析
- 安全性一票否决：蜜罐 / CRITICAL → 直接 C 级

## 5. 已知限制

1. **推特 API Token 失效**：当前环境的 6551 Token 返回 401，推特引擎降级为 null；链上引擎不受影响
2. **Supabase 缓存**：旧缓存不含 `twitter_narrative` 字段，已加自动失效逻辑；需在生产环境执行 SQL 迁移
3. **DexScreener 限流**：服务器启动时调度器批量请求可能暂时耗尽配额，影响首批叙事获取
